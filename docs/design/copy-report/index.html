Sands · NAK-535 · The "Copy report" row in Help

The anonymous diagnostics report, as the last row of the Help section of the approved settings (rail A · Dune). Press the button: the report is poured into the clipboard and a heap of sand settles at the foot of the button, then leaves by itself. Beside the button, the GitHub mark is always there: it opens a new issue for Sands, where the report is pasted. Once the report is copied the mark takes the primary colour, so the next step shows itself. Switch "Clipboard tool" to "Missing" to see the guided message. Every state is also drawn side by side under the panel.

Why it is not generic: the confirmation is not a toast nor a green tick. It is the same settling heap as the rail marker, so "done" reads as sand that has landed.
