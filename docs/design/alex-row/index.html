Sands · NAK-545 · The "When a Sands timer ends" row

Where it lives: Sands settings, section "Alerts & sounds", last row. Same title, same help and same three choices as in Alex settings (NAK-492); one value, kept by Alex, so both pages always agree. The default is "Alarm in the Alex island" (D466). Click a choice in the panel: the small bar under it shows what happens when the timer rings. Switch "Alex" to "Turned off" or "Not installed" to see the greyed row with its reason and the GitHub mark that opens the guide.

Why it is not generic: the row does not explain the choice with more text or a lock. It draws the bar at the ring: the Sands chip is always there, and Alex's seat beside it is quiet, paged, carrying the alarm, asleep or empty (dashed). The dashed edge of the greyed control is that same empty seat.
